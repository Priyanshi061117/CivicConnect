# CivicConnect  — AI Civic Complaint Router

An AI-powered municipal complaint management system that helps citizens submit civic complaints, automatically routes them to the appropriate municipal department, and enables officials to manage and track complaint resolution.

OVERVIEW

CivicConnect is a web-based civic complaint management platform designed to improve the efficiency and transparency of municipal complaint handling.
The system uses machine learning to classify complaints into relevant municipal departments. It also incorporates priority assessment and duplicate complaint detection to help officials organize and process complaints more effectively.
The application provides separate interfaces for citizens, municipal officials, and administrators.

FEATURES

1)Citizen Portal

-User registration and authentication.

-Submit civic complaints with descriptions and locality information.

-View submitted complaints and their current status.

-Track complaint progress and status history.

-View complaint priority and relevant classification information.


2)AI-Powered Complaint Routing

-Text classification using TF-IDF feature extraction and a Linear Support Vector Machine (Linear SVM).

-Automatic prediction of the appropriate municipal department.

-Rule-based complaint priority assessment.

-Similarity-based duplicate complaint detection.

-Duplicate complaint review support.



3)Official Dashboard

-View and manage the complaint queue.

-Review complaints assigned to municipal departments.

-Update complaint statuses.

-Maintain complaint status history.

-Review potential duplicate complaints.

-View complaint analytics.



4)Administrator Dashboard

-Access administrative analytics.

-Manage users and municipal departments.

-Monitor complaint management activity.
